## 🧑‍💻 About Me

I'm **Ferli Andriansyah** — a Fullstack IoT Developer with nearly 2 years of professional experience building and deploying web applications with **Laravel**, **React**, and **RESTful APIs**. Most of my work lives where field operations meet software: real-time telemetry dashboards, role-based access systems, and database work that makes reporting 30–40% faster. I also use AI-assisted tooling to accelerate development and debugging.

**What I do:**
- 📡 **Real-time IoT dashboards** — telemetry ingestion, live metrics, fuel analytics, interactive maps
- ⚙️ **APIs & backend** — Laravel, JWT authentication, RBAC, audit logging
- 🗄️ **Data & infrastructure** — query optimization, server management, production deployment
